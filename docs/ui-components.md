# Компоненты интерфейса

PrintLab использует Mantine 9.7.4 (`@mantine/core` и `@mantine/hooks`) для общих
элементов интерфейса. Библиотека поддерживает React 19 и CSS Modules, которые
уже используются в проекте. Версии закреплены в package.json/package-lock.json.

## Где настраивать оформление

- `src/app/theme.ts` — общая тема Mantine: палитра, шрифт, скругления и стандартные
  размеры компонентов. Одинаковый оттенок заполненных кнопок в обеих темах
  обеспечивает контраст текста; доступность проверяется Axe в Playwright.
- `src/app/styles.css` — фон приложения, текст, границы и переменные фирменных цветов.
- `src/pages/home/styles/home-page.module.css` — адаптивная сетка и компоновка
  рабочей области. Стили полей и кнопок здесь повторно не реализуются.
- `src/features/model-viewer/styles/model-viewer.module.css` — область 3D и расположение
  готовых ActionIcon. Геометрия, вращение и обработчики мыши/касания остаются в модуле просмотра.

MantineProvider находится в корне приложения. Смена темы использует его общий
контекст и сохраняется между перезагрузками. Дополнительные провайдеры в страницах
не нужны. Удалены две неиспользуемые копии старых CSS-файлов.

## Используемые компоненты

| Элемент                                                  | Компонент Mantine       |
| -------------------------------------------------------- | ----------------------- |
| Основные действия, повтор запроса, удаление из просмотра | Button                  |
| Смена темы, управление 3D                                | ActionIcon              |
| Выбор материала и параметров                             | NativeSelect            |
| Числовые ограничения                                     | NumberInput             |
| Карточки рабочей области и результатов                   | Paper                   |
| Ошибки и неполный подбор                                 | Alert                   |
| Результат открытия STL                                   | Notification            |
| Состояние загрузки                                       | Loader / Button loading |
| Свойства материала и детали запроса                      | Accordion               |
| Сравнение вариантов                                      | Table + ScrollContainer |
| Статусы и выбранный вариант                              | Badge                   |
| Заполнение по испытаниям                                 | RingProgress            |

NativeSelect сохраняет нативные семантику, клавиатурную навигацию и выбор на телефоне.
NumberInput передаёт десятичные значения в обычном формате с точкой, включая ввод
с запятой. Целочисленные параметры запрещают дробную часть. И ввод, и изменение
стрелками вызывают сброс устаревшего результата; сами по себе они не запускают запрос.
Валидация диапазонов и целых значений остаётся в существующих парсерах запросов.

Таблицы прокручиваются внутри карточки на узких экранах, а не растягивают страницу.
Поля, переключение темы и загрузка файла доступны без мыши. В загруженном 3D-просмотре
нет надписей, переключателей каркаса или ракурса. Удаление из просмотра остаётся
красной кнопкой и очищает локальную модель.

## Проверки изменений

`npm run check` проверяет формат, lint, поведение, покрытие и production-сборку.
`npm run test:e2e` проверяет обе темы, мобильную и настольную компоновку, контраст,
таблицы, ошибки, выбор STL и 3D-взаимодействия. Сценарии интеграции с локальным
слайсером включаются отдельно; публичный сервер не используется в обычном CI.

`src/test/render.ts` оборачивает компоненты в тестовый MantineProvider. Его тема
отключает анимацию раскрытия только в тестах; проверки не зависят от таймеров анимации.
