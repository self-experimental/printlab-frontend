# Статические ресурсы интерфейса

- `images/printlab-logo.svg` — файл «Лого 2.svg», экспортированный пользователем из Figma. Сохранён без изменения байтов; используется в шапке и как favicon.
- `icons/sun.svg`, `icons/moon.svg` — значки переключения темы.
- `design/*.svg` — предоставленные экспорты Figma, сохранённые без изменений как ориентиры для вёрстки.
- `screenshots/*.png` — все 10 скриншотов проверки интерфейса, ранее находившиеся в docs/screenshots.

Экспорт логотипа имеет размер 71 × 69 и содержит встроенный PNG. Это предоставленный исходный SVG-экспорт, а не перерисованный контур. Пропорции сохраняются через object-fit: contain.

Ресурсы подключаются через импорты Vite; новые изображения и иконки интерфейса добавляйте сюда. Скриншоты проверок находятся в src/static/screenshots; они не используются интерфейсом и не попадают в сборку без импорта.
