# Проверочные модели

- `triangle.stl` — один треугольник для проверки локального просмотра. Экспериментальных данных для расчёта нет.
- `cube-20.stl` — замкнутый куб со стороной 20 мм, соответствующий исследованному образцу backend. Для проверки выберите PLA, изгиб, 40 Н, запас 2, слой 0,2 мм, приоритет минимального расхода, остальные поля оставьте без ограничений. Ожидаются 15% заполнения, 13,74 г и 36 минут.

Эти файлы проверяют работу приложения; результат относится к данным испытанного образца.

`stepped-block.stl` — замкнутая L-образная деталь 30 × 30 × 15 мм, не совпадающая с
исследованными кубами. Подходит для нового режима подбора печати через Bambu Studio;
подтверждённой нагрузки для неё в базе нет.
